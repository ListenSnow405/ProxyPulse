# ProxyPulse

ProxyPulse 是一个个人使用的本地代理节点监测工具。它会定时通过 HTTP CONNECT 或 SOCKS5 节点访问测试地址，记录完整延迟、分阶段耗时、成功率，以及经过防抖确认的 Timeout 时间段。

所有数据默认保存在本机 `data/proxy-monitor.db`，网页与接口只监听 `127.0.0.1`。

## 快速开始

环境要求：

- Windows 10/11
- Python 3.11 或更高版本
- Node.js 22.13 或更高版本（只在首次构建网页时需要）

第一次使用，在 PowerShell 中运行：

```powershell
.\setup.ps1
.\start.ps1
```

`start.ps1` 会打开 `http://127.0.0.1:8765/`。以后直接运行它即可；按 `Ctrl+C` 停止监测服务。

如果 PowerShell 阻止本地脚本，可以只为当前窗口临时放行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\start.ps1
```

不希望自动打开浏览器时：

```powershell
.\start.ps1 -NoBrowser
```

## 添加节点

在网页右上角选择“添加节点”，填写：

- 节点名称
- `HTTP CONNECT` 或 `SOCKS5`
- 可直接连接的主机名/IP 和端口
- 可选用户名与密码

常见本地代理软件可能提供类似配置：

```text
HTTP / mixed 端口：127.0.0.1:7890
SOCKS5 端口：     127.0.0.1:7891
```

实际端口请以你的 Clash、Mihomo、sing-box 或其他代理软件配置为准。

如果多个远端节点都藏在同一个本地 selector 和端口后面，ProxyPulse 测到的是“当前被选中的节点”，无法同时区分各远端节点。若要并行监测每个远端节点，需要让代理核心为它们暴露独立监听端口，或后续增加控制接口集成。监测程序不会自动切换你正在使用的 selector。

## 监测逻辑

默认每 10 秒探测一次两个独立目标：

```text
连接代理 TCP
→ HTTP CONNECT / SOCKS5 握手
→ 与目标进行 TLS 握手
→ 发送 HTTP GET
→ 等待响应首字节与完整响应头
```

每次探测记录：

- 代理 TCP 连接耗时
- 代理握手耗时
- TLS 握手耗时
- TTFB（首字节）
- 总耗时
- HTTP 状态码
- Timeout 所在阶段
- DNS、认证、拒绝连接、TLS 等错误类型

任意一个测试目标返回合法 HTTP 响应，就证明代理链路仍然可达。只有所有目标都 Timeout 才把这一轮归类为 Timeout，这可以减少单个测试网站故障造成的误报。

延迟曲线、平均值和 P95 始终使用列表中的第一个测试目标，避免主目标失败时混入另一条网络路径；后备目标只用于确认链路是否仍可达。若主目标失败但后备目标成功，该轮会保持可用，同时在曲线中留下断点。

## Timeout 时间段

默认规则：

```text
连续 3 次失败  → 确认故障
连续 2 次成功  → 确认恢复
```

事件开始时间回溯到第一条连续失败，结束时间回溯到第一条连续恢复成功。因此图表既有抗抖确认，也能尽可能接近真实故障区间。

采样是离散的：10 秒间隔意味着故障起止时间约有 ±10 秒的不确定性。Timeout 在折线中显示为断点，而不是伪装成一个“8 秒延迟”的成功请求；确认后的事件会以红色背景和状态条显示。

电脑休眠、程序停止或采样明显迟到会被标记为灰色“未采样”区间，折线也会真正断开，不会误算成节点 Timeout。若正在发生的故障遇到采样中断，事件会在最后一条观测处以“结束未确认”关闭。

仪表盘中的“成功采样率”只统计实际执行的探测；“采样覆盖率”则将应执行的轮次作为分母，用于识别休眠或服务停机造成的数据空窗。

## 设置

网页右上角可以修改：

- 探测间隔
- TCP 连接超时
- 整体请求超时
- 故障与恢复确认次数
- 历史数据保留天数
- 1～5 个测试目标

建议把其中一个测试目标替换成你自己控制的轻量 `/health` 地址。

也可以复制 `config.example.toml` 为 `config.toml`，在首次创建数据库前修改默认值。网页中保存的设置位于 SQLite，之后以网页设置为准。

## 数据与安全

- 服务只允许绑定 `127.0.0.1` 或 `localhost`；个人版本会拒绝监听 `0.0.0.0` 等外部地址。
- 节点用户名和密码不会通过查询接口返回，也不会写入探测错误日志；编辑节点时可一键清除已保存凭据。
- Windows 下凭据使用当前用户的 DPAPI 加密后再写入 SQLite，复制数据库到其他账户或电脑无法解密。非 Windows 的兼容模式仅做编码保护，不应保存高价值公网代理凭据。
- HTTP Basic 与 SOCKS5 用户名密码本身不会加密代理入口链路。连接公网代理时应了解这一风险；本机代理监听端口不受此问题影响。
- 测试目标只允许绝对 `http://` 或 `https://` URL，最多 5 个。

## 开发与验证

后端只使用 Python 标准库。开发时可分别运行：

```powershell
python -m monitor
npm run dev
```

开发网页位于 `http://localhost:5173/`，API 位于 `http://127.0.0.1:8765/`。

运行自动测试：

```powershell
python -m unittest discover -v
```

测试覆盖 HTTP CONNECT、SOCKS5、握手 Timeout 分类、凭据脱敏、事件起止回溯和节点 API。

项目中的主要文件：

```text
monitor/probe.py       代理协议与分阶段探测
monitor/database.py    SQLite、统计和事件状态机
monitor/service.py     固定周期调度与并发控制
monitor/server.py      本地 API 与静态网页服务
app/page.tsx           监测仪表盘
config.example.toml    默认配置示例
setup.ps1              首次安装与构建
start.ps1              日常启动
```
